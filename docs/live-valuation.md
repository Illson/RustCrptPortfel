# Живая оценка локальных портфелей

Цель: на `/portfolios` автоматически оценивать уже импортированные позиции в USD по [публичному CoinGecko API без ключа](https://docs.coingecko.com/docs/keyless-public-api), показывать общую стоимость, стоимость и долю позиции. Приложение не синхронизирует количество монет с провайдером. Котировки показываются отдельно от даты снимка остатков; стоимость из CSV не используется.

- Список активов (`/coins/list`) загружается целиком без параметров из портфеля. В запросе цен (`/simple/price`) передаются только публичные CoinGecko ID и опции расчёта цены, а не названия из файлов, количества, файлы или история. Подключение только для локального Development: у публичного API общий лимит по IP, это не источник для продакшн-обновлений по расписанию.
- Автоматически используется явно указанный `asset_id` вида `coingecko:bitcoin` или однозначное совпадение полного названия для позиции без ID. Есть короткий список подтверждённых исключений: [Dash](https://www.coingecko.com/en/coins/dash), [IOTA](https://www.coingecko.com/en/coins/iota), [Terra Classic](https://www.coingecko.com/en/coins/terra-luna) (не Terra 2). Исключение действует только если совпали ID, название и тикер в каталоге. Тикер и частичное совпадение сами по себе не выбирают актив; неоднозначную монету можно выбрать из каталога в интерфейсе. Сопоставления сохраняются отдельно в браузере, формат старых портфелей не меняется.
- Допускается, что время котировки опережает часы сервера или браузера не более чем на 60 секунд. Исходная метка времени сохраняется. Котировки с большим опережением, старше 15 минут, без времени или цены не входят в стоимость. При неполном покрытии отображается промежуточная сумма, процентные доли не рассчитываются. Стоимость и сумма вычисляются без округления; USD округляется для отображения до центов, доли — до двух знаков по правилу ближайшего чётного.
- Обновление при открытии и изменении выбранных монет, также есть кнопка обновления. Сервер кэширует каталог на 6 часов, цены на минуту, ограничивает обращения к источнику (4 вызова за минуту на экземпляр). Нет фонового опроса. При ошибке уже полученные котировки можно показывать только пока они актуальны.
